# EXP01 — Baseline Stability

## Objective
Characterize normal 24–48 h variation using currently available measurements.

## Required data
- temperature;
- pH;
- PT550 relative light;
- manual salinity SG at defined checkpoints;
- optional XKC state only if installed;
- intervention/observation notes.

## Explicit exclusions
No ORP, EC, float-switch or flow data may appear as measured variables.

## Analysis
Compute mean, standard deviation, minimum and maximum for temperature and pH; describe the light cycle; report missing-data periods.
