# EXP03 — Controlled pH Perturbation

## Objective
Evaluate sensor + rule + report response to a small, documented pH disturbance in the experimental saltwater system.

## Required controls
- Use teacher-approved diluted reagent and micro-step additions only.
- Record every addition volume and time.
- Define a stop pH before the experiment.
- Keep recovery/change-water procedure ready.

## Data
- calibrated pH;
- pH voltage;
- temperature;
- intervention timeline;
- deterministic rule events;
- AI explanation generated only after rule evaluation.
