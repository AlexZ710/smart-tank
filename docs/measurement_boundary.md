# Measurement Boundary - smart-tank

> Frozen in Session 01. Defines which variables are automatically measured,
> manually entered, optional, or unavailable. No code, chart, schema, or
> report may claim a value outside this boundary as an automatic measurement.

## 1. Automatically measured variables

| Variable | Sensor chain | Units | Notes |
|---|---|---|---|
| Water temperature | DS18B20 -> ESP32-S3 GPIO4 (1-Wire) | degC | Calibrated digital probe. |
| pH | SEN0161-V2 -> ADS1115 A1 -> I2C | pH units | Requires periodic buffer calibration (4.00/6.86/9.18). |
| Ambient light signal | PT550 -> ADS1115 A3 -> I2C | Raw ADC / relative | Relative trend only. **Not PAR/PPFD** unless calibrated against a suitable reference; must never be labeled lux/PAR/PPFD uncalibrated. |
| Water level (only if hardware present) | XKC-Y25-T12V -> isolation -> GPIO | Boolean/present-absent | Nullable; disabled when hardware absent. |

## 2. Manual input variables

| Variable | Method | Units | Notes |
|---|---|---|---|
| Salinity | Refractometer or hydrometer, entered by operator | ppt / SG | Manual entry only; never an automatic field. |
| Maintenance events | Operator log (water change, feeding, cleaning) | n/a | Event metadata for experiment context. |

## 3. Optional variables (hardware-dependent)

- XKC-Y25-T12V water level: included only if physically available, wired only
  through proper electrical isolation/level conversion. All software paths
  must tolerate its absence (nullable/disabled). The project must remain
  fully runnable without it.

## 4. Unavailable / forbidden variables

The following are explicitly absent from the hardware baseline and **must not
be reintroduced, implemented, or fabricated**:

- ORP (oxidation-reduction potential).
- EC / conductivity.
- ZP4510 float switches.
- FS300A flow sensor.

## 5. Derived values and truth rules

- Derived values (deltas, rolling averages, trends, rule-engine states) may
  be computed only from the measured/manual variables above.
- Ammonia is **not** an automatically measured value. Any ammonia reference
  in reports is a manual test-kit entry or an explicit literature assumption.
- Salinity drift experiments use manual refractometer readings; the system
  never interpolates or infills salinity as if sensed.
- No chart or AI report may present a manual or unavailable variable as a
  live automatic measurement.

## 6. Signaling boundary

- The system is monitoring-and-alert only. Alerts are advisory text/status
  generated by the deterministic rule engine and bounded AI report layer.
- No actuator output, no dosing, no mains switching exists in any layer.
